# 整体优化记录

本轮覆盖几何后端、共享求解器、分组准备、输入边界和 URDF 元数据导出。
中英文 README 的固定点标定原理图恢复为默认显示。

## 正确性

- 旋转导数使用当前偏差处的 RPY 解析轴，修复仅在零偏差处正确的问题。
  新增非零偏差有限差分检查；原实现的 UR10 `Joint2.roll` 导数最大绝对误差约为 0.0454 m/rad。
- 单层固定关节的扰动传递到折叠于同一活动父关节的下游关节和坐标系，
  与重新生成的扰动 URDF 对照验证。TCP 祖先路径外的参数导数为零。
- 链式固定关节按拓扑拒绝，即使前一个固定变换是单位矩阵也不会误接受。
  运动学求值异常时仍恢复模型 placement。
- 阻尼更新分两次乘衰减系数，避免系数平方下溢吞掉仍可表示的修正量。
- 拟合初值必须位于参数边界内，包括非活动参数；越界时抛出 `ValueError`。
- URDF 元数据由 JSON 解码器处理转义，保留字面量 `\u002d` 和反斜杠；
  拒绝 NaN/Infinity 元数据，错误发生时保留已有目标文件。

## 性能与维护

- 每个关节批量计算几何导数，复用初始化时解析的列索引和 origin 变换。
  几何后端只计算前向运动学，不再计算未使用的关节速度雅可比。
- 回溯跳过与当前状态相同、或与上次已尝试状态相同的投影候选；
  仍继续尝试更短步长。完全被边界阻挡时无需重复运行运动学。
- 接触组名称通过字典解析距离端点，避免为每条距离重复线性查找。
- 共享求解器状态增加类型协议，明确矩阵、误差和目标值接口。

在本机、相同 UR10 配置和 18 参数下，各计时 5 轮、每轮 1000 次：
几何后端求值中位耗时约从 **132.47 μs/次** 降到 **69.27 μs/次**，减少约 **48%**。
这是一项微基准，不表示完整标定或其他机器的加速比例。

复现当前版本计时：

```bash
PYTHONPATH=. python scripts/benchmark_geometric_backend.py
```

## 第二轮：采样排序与分组计算

- 无间距约束的候选排序复用未改变接触组的矩阵，只重算候选所属组，
  保留各组等权、sigma 加权和总样本数归一化。有间距约束时继续完整重算。
- 分组报告复用已中心化的位置计算 RMS 和逐样本误差，每组中心化从三次降为一次。
- 距离权重先分别开平方再相乘，避免 `样本数 * 权重` 中间溢出；
  权重为 `1e308`、最终加权行仍有限的情况已加入回归测试。

排序测试逐项对照完整重算，覆盖不等组大小、首/中/末组、sigma 权重、
有无距离约束以及重复候选，检查奇异值、有效秩、条件数和最终推荐顺序。

本机解析后端基准：8 组，每组 25 个样本，100 个候选，无间距约束；
5 轮、每轮排序 5 次。每次排序中位耗时约从 **17.13 ms** 降到 **5.15 ms**，
减少约 **70%**。该结果衡量此工作量下的排序性能；真实后端的运动学耗时会影响收益。

## 第三轮：URDF 一致性与极端坐标

- 几何后端和导出模块共用独立的 URDF origin 解析模块，统一缺省零值、
  三分量长度和有限数值检查。几何后端在构建 Pinocchio 模型前报告这些错误。
- 拒绝重复或空白关节名、非 `robot` 根元素，避免字典索引静默覆盖同名关节。
  导出失败时保留已有目标文件。
- 从几何结果生成 origin 更新时，拒绝重复参数、未知分量、单位不符、
  非有限估计以及相加溢出的 origin，避免覆盖前一个参数或将非法值传到导出阶段。
- 中心化保持原有常规路径；只有中间运算溢出时才尝试以范围中点为基准。
  `[-1e308, +1e308]` 的有限残差和 RMS 可以正确计算，真正超出浮点范围的残差仍报错。

此轮侧重正确性和维护性，不新增性能收益声明。

## 第四轮：单组噪声权重与后端校验

- 修复单接触组快捷路径忽略 `sigma_m` 的问题。只有未设置 sigma 且没有
  间距约束时才使用原单点路径；设置 sigma 后，阻尼步长和奇异值均按加权系统计算。
- 使用等价阻尼关系校验：将 Jacobian 和残差同时除以 sigma，等价于在未加权
  系统中将阻尼乘以 sigma²。回归测试覆盖 sigma 为 0.01 和 100 的单步结果，
  并确认极大 sigma 不会掩盖物理残差超差。
- 两个标定 API 共用后端元数据校验，在数值求值前拒绝非法 DoF、重复或空白
  关节名、将单个字符串误当名称序列等输入，统一报告 `ValueError`。
- 中英文 README 同步说明单组 sigma 的语义；原理图继续默认显示。

## 第五轮：采样诊断与 JSON 接口

- 可观性报告校验整数秩、矩阵行数、奇异值数量与降序、最小可观奇异值，
  并检查条件数与谱及秩的一致性。NaN 和矛盾的报告在构造时被拒绝。
- NumPy 整数和实数标量转换为 Python 标量，避免 `to_dict()` 后严格 JSON
  序列化失败；欠约束报告继续将无限条件数输出为 `null`。
- 候选排名校验活动关节顺序和 rank gain 与基线是否一致，在结果构造器中
  统一排序。外部组装的候选列表也能正确给出 `recommended`，并保留源索引用于追溯。
- 此轮有意收紧了手动构造报告的输入要求：不一致的数据会抛出 `ValueError`。

## 第六轮：CLI 选项与导出兼容性

- 修复 `--output` 搭配缺少等号的 `--group` 参数时出现的未捕获 `IndexError`。
  输出路径检查复用 NAME=VALUE 解析，空值也会明确报错。
- 单点模式拒绝仅适用于分组的权重、sigma 和间距选项；距离权重或 sigma
  必须对应一条实际距离测量，避免用户以为选项生效而程序实际忽略。
- 仅指定验证组时明确提示需要训练组。错误调用退出码为 2，并保留已有输出文件。
- URDF 内嵌元数据使用 ASCII JSON 转义，使中文、表情以及 XML 不允许直接
  出现的 Unicode 字符均能通过 JSON 无损还原，导出的 XML 仍可解析。
