# 整体优化记录

本轮覆盖几何后端、共享求解器、分组准备、输入边界和 URDF 元数据导出。
中英文 README 的固定点标定原理图恢复为默认显示。

## 正确性

- 旋转导数使用当前偏差处的 RPY 解析轴，修复仅在零偏差处正确的问题。
  新增非零偏差有限差分检查；原实现的 UR10 `Joint2.roll` 导数最大绝对误差约为 0.0454 m/rad。
- 单层固定关节的扰动传递到折叠于同一活动父关节的下游关节和坐标系，
  与重新生成的扰动 URDF 对照验证。TCP 祖先路径外的参数导数为零。
- 链式固定关节按拓扑拒绝，即使前一个固定变换是单位矩阵也不会误接受。
  运动学求值异常时仍恢复模型 placement。
- 阻尼更新分两次乘衰减系数，避免系数平方下溢吞掉仍可表示的修正量。
- 拟合初值必须位于参数边界内，包括非活动参数；越界时抛出 `ValueError`。
- URDF 元数据由 JSON 解码器处理转义，保留字面量 `\u002d` 和反斜杠；
  拒绝 NaN/Infinity 元数据，错误发生时保留已有目标文件。

## 性能与维护

- 每个关节批量计算几何导数，复用初始化时解析的列索引和 origin 变换。
  几何后端只计算前向运动学，不再计算未使用的关节速度雅可比。
- 回溯跳过与当前状态相同、或与上次已尝试状态相同的投影候选；
  仍继续尝试更短步长。完全被边界阻挡时无需重复运行运动学。
- 接触组名称通过字典解析距离端点，避免为每条距离重复线性查找。
- 共享求解器状态增加类型协议，明确矩阵、误差和目标值接口。

在本机、相同 UR10 配置和 18 参数下，各计时 5 轮、每轮 1000 次：
几何后端求值中位耗时约从 **132.47 μs/次** 降到 **69.27 μs/次**，减少约 **48%**。
这是一项微基准，不表示完整标定或其他机器的加速比例。


## 第二轮：采样排序与分组计算

- 无间距约束的候选排序复用未改变接触组的矩阵，只重算候选所属组，
  保留各组等权、sigma 加权和总样本数归一化。有间距约束时继续完整重算。
- 分组报告复用已中心化的位置计算 RMS 和逐样本误差，每组中心化从三次降为一次。
- 距离权重先分别开平方再相乘，避免 `样本数 * 权重` 中间溢出；
  权重为 `1e308`、最终加权行仍有限的情况已加入回归测试。

排序测试逐项对照完整重算，覆盖不等组大小、首/中/末组、sigma 权重、
有无距离约束以及重复候选，检查奇异值、有效秩、条件数和最终推荐顺序。

本机解析后端基准：8 组，每组 25 个样本，100 个候选，无间距约束；
5 轮、每轮排序 5 次。每次排序中位耗时约从 **17.13 ms** 降到 **5.15 ms**，
减少约 **70%**。该结果衡量此工作量下的排序性能；真实后端的运动学耗时会影响收益。

## 第三轮：URDF 一致性与极端坐标

- 几何后端和导出模块共用独立的 URDF origin 解析模块，统一缺省零值、
  三分量长度和有限数值检查。几何后端在构建 Pinocchio 模型前报告这些错误。
- 拒绝重复或空白关节名、非 `robot` 根元素，避免字典索引静默覆盖同名关节。
  导出失败时保留已有目标文件。
- 从几何结果生成 origin 更新时，拒绝重复参数、未知分量、单位不符、
  非有限估计以及相加溢出的 origin，避免覆盖前一个参数或将非法值传到导出阶段。
- 中心化保持原有常规路径；只有中间运算溢出时才尝试以范围中点为基准。
  `[-1e308, +1e308]` 的有限残差和 RMS 可以正确计算，真正超出浮点范围的残差仍报错。

此轮侧重正确性和维护性，不新增性能收益声明。

## 第四轮：单组噪声权重与后端校验

- 修复单接触组快捷路径忽略 `sigma_m` 的问题。只有未设置 sigma 且没有
  间距约束时才使用原单点路径；设置 sigma 后，阻尼步长和奇异值均按加权系统计算。
- 使用等价阻尼关系校验：将 Jacobian 和残差同时除以 sigma，等价于在未加权
  系统中将阻尼乘以 sigma²。回归测试覆盖 sigma 为 0.01 和 100 的单步结果，
  并确认极大 sigma 不会掩盖物理残差超差。
- 两个标定 API 共用后端元数据校验，在数值求值前拒绝非法 DoF、重复或空白
  关节名、将单个字符串误当名称序列等输入，统一报告 `ValueError`。
- 中英文 README 同步说明单组 sigma 的语义；原理图继续默认显示。

## 第五轮：采样诊断与 JSON 接口

- 可观性报告校验整数秩、矩阵行数、奇异值数量与降序、最小可观奇异值，
  并检查条件数与谱及秩的一致性。NaN 和矛盾的报告在构造时被拒绝。
- NumPy 整数和实数标量转换为 Python 标量，避免 `to_dict()` 后严格 JSON
  序列化失败；欠约束报告继续将无限条件数输出为 `null`。
- 候选排名校验活动关节顺序和 rank gain 与基线是否一致，在结果构造器中
  统一排序。外部组装的候选列表也能正确给出 `recommended`，并保留源索引用于追溯。
- 此轮有意收紧了手动构造报告的输入要求：不一致的数据会抛出 `ValueError`。

## 第六轮：CLI 选项与导出兼容性

- 修复 `--output` 搭配缺少等号的 `--group` 参数时出现的未捕获 `IndexError`。
  输出路径检查复用 NAME=VALUE 解析，空值也会明确报错。
- 单点模式拒绝仅适用于分组的权重、sigma 和间距选项；距离权重或 sigma
  必须对应一条实际距离测量，避免用户以为选项生效而程序实际忽略。
- 仅指定验证组时明确提示需要训练组。错误调用退出码为 2，并保留已有输出文件。
- URDF 内嵌元数据使用 ASCII JSON 转义，使中文、表情以及 XML 不允许直接
  出现的 Unicode 字符均能通过 JSON 无损还原，导出的 XML 仍可解析。

## 第七轮：复用单点残差与独立接触组计算

  平均 Jacobian 也只在有间距测量时计算。
- 新增五个回归用例，覆盖中心化复用、sigma 权重、极大坐标下的独立组，

## 第八轮：SVD 投影范围、秩判定和采样矩阵

- 修复残差投影中间溢出导致拒绝有限修正量的问题。例如四行 Jacobian
  均为 `1e100`、误差均为 `1e308` 时，无阻尼修正量应为 `1e208`。
  现在仅在常规计算失败时归一化误差，并用浮点尾数/指数恢复修正量。
  已成功求得的有限方向保留原值，避免全局缩放吞掉较小的误差分量。
- 真实不可表示的修正量仍报错；不可表示的奇异值谱明确报错，避免错误
  返回零秩和零步长。
- 零偏、几何标定和采样报告共用相对秩判定。先归一化奇异值再比较阈值，
  修复次正规数下阈值乘法舍入到最大奇异值、导致所有方向均被排除的问题。
- 可观方向使用 SVD 降序谱的连续切片，避免每次投影复制整个左奇异向量
  矩阵。无间距的采样信息矩阵只中心化 Jacobian，位置残差不再参与计算。

新增 24 个测试用例，覆盖投影溢出回退、大小修正量共存、真正溢出、
次正规数秩、零谱，以及高矩阵/宽矩阵在不同秩和阻尼下与解析截断
伪逆的比较。`hmotion` 环境完整测试为 **401 passed**；三个 UR10 示例
继续通过，双球窝及几何独立验证 RMS 分别为 **0.036255 mm** 和 **0.143 mm**。

## 第九轮：批量几何求值、QR 采样信息和距离数值稳定性

### 行为与算法

- 新增可选批量后端接口 `position_and_geometric_jacobian_batch`，同一个参数
  向量只准备一次偏差模型，随后计算整批姿态。标定器自动使用该接口，校验
  返回形状和有限值，并复制后端缓冲区。只有逐样本方法的自定义后端继续可用。
  输入错误、求值中途异常以及正常完成后均恢复模型 placement；输出与逐样本
  求值逐项一致。只估计平移时复用名义旋转，跳过未使用的旋转导数轴计算。
- 无间距约束的候选排序复用各组的 QR 因子。追加一个姿态的中心化散布矩阵
  更新为 `S_new = S_old + n/(n+1) * delta.T @ delta`，其中 delta 是新姿态
  Jacobian 与原组均值之差。通过追加三行实现此更新，再计算较小矩阵的 SVD；
  实际计算不形成正规方程。各组等权、sigma、真实观测行数归一化和结构性
  零奇异值数量均保持一致。位移中间溢出时回退到完整中心化。
- 每条已知距离使用其两个端点的相对中心。修复一个无关远处接触组会令两个
  端点实际 **2 m** 的间距被报告为 **0 m** 的问题，也保留世界坐标分别舍入
  后无法显示的亚 ULP 中心间距。代表样本之差溢出时使用四项缩放回退。
- sigma 的倒数不可表示或成为次正规数时，用尾数/指数计算加权行，避免
  把仍有限的 Jacobian、残差及零行变成 Infinity/NaN。距离导数的舍入阈值
  先乘 epsilon 再累加，避免把有效的大导数误判为零。
- 求解器允许一个不可表示的奇异方向系数映射为多个有限参数。例如一行
  四列均为 `1e-308`、误差为 4 时，无阻尼参数步应为四个 `1e308`。
  常规浮点计算失败后，以标准库 Decimal 做具有动态精度的右基投影，保留
  大数相消后的微小模式；无新增依赖。真实不可表示的参数步仍报错。
- 复用校验时规范化的关节名元组，修复 NumPy 名称序列已经通过校验、随后
  按名称固定关节却因没有 `.index()` 而报 `AttributeError` 的问题。

## 第十轮：已知间距候选缓存与独立验证求值

### 行为与算法

- QR 候选缓存扩展到带已知间距的接触组。各组的中心化 Jacobian 仍以
  QR 因子保留；新增姿态只更新目标组的三行散布矩阵，以及与目标组相连的
  距离行。其余距离行仅按新增观测数重缩放。目标组位置和 Jacobian 使用与
  完整重建相同的中心化，以保留小间距及接近重合时的误差行为。真实观测
  行数、噪声权重、秩和候选顺序的定义不变。
- 一个候选时直接计算完整矩阵，省去无法复用的缓存准备。QR 因子溢出时
  同样回退完整矩阵：原始 QR 范数不可表示，并不意味着按观测数归一化的
  奇异值也不可表示。信息矩阵不再中心化未参与任何距离约束的位置。
- 提取距离导数的共享计算。均值之差或投影溢出、但噪声加权后的导数仍
  可表示时，只对受影响的列缩放并用尾数/指数恢复，其他列保持原来的
  数值路径。实际距离超过浮点范围时明确报错，避免将无限长度当作零导数。
- Decimal 求解回退使用独立的精度、舍入方式、指数范围和 trap 设置，避免
  调用者的 Decimal 上下文导致浮点标定失败；调用者设置及 flags 保持不变。
- `evaluate_groups` 支持可选的 `position_batch` 和
  `geometric_position_batch`。Pinocchio 仅计算 TCP 位置，省去整批 Jacobian
  的计算和存储；几何模型只准备一次偏差，并跳过导数轴。校验返回形状、
  实数和有限值，复制复用缓冲区。没有这些方法的后端沿用原有求值接口。
  正常及中途异常均恢复几何模型，报告与原求值路径逐项一致。

### 数值与求值路径

- 可观性归一化还原混合尺度矩阵中的弱列。六行两列分别含 `±1e-15`
  和 `±最小正浮点数` 时，先除以 `sqrt(6)` 会把第二列清零；恢复单位后
  第二个奇异值仍可表示，极小秩阈值下应为满秩。异常路径延后归一化，
  同时避免缩小原始矩阵再次擦除弱列。正常谱值保留原路径。
- 条件数使用 Python 浮点除法，超过浮点范围时保留 Infinity，并在 JSON
  中输出 `null`；调用方设置 NumPy 溢出抛错时也能生成诊断。
- SVD 投影溢出后采用局部 Decimal 上下文恢复投影，避免全局缩放残差
  擦除大项抵消后的微小余项。16384 行常量矩阵、大正负残差与 `1e-100`
  余项的解析修正为 `6.103515625e-105`，原路径返回零。次正规投影也会
  恢复；1024 行、系数 `1e-300`、一个最小正残差的修正约 `4.82e-27`。
  阻尼后步长确实下溢为零时，仍保留未阻尼剩余修正量。高精度运算仅在
  异常投影路径执行，不继承或修改调用方的 Decimal 精度、舍入和陷阱。重复指数充分时复用
  二次幂，短向量保留直接计算。
- 连续活动列改用切片视图，避免高级索引复制整批 Jacobian。一般索引仍
  保留顺序、重复列与原有越界行为，最终矩阵与残差保持独立所有权。
  单接触小块保留原路径，多组共享一次列检测；候选缓存使用对应布局。
- 多关节旋转导数合并为一次叉乘。参数列可交错，TCP 后代参数保持零导数；
  单关节和纯平移路径不分配额外的杆臂数组。已有模型恢复行为保持一致。
- 构造时为零平移的 TCP 进入快速检查路径，确认当前平移仍为零后跳过
  速度平移；构造时非零则沿用原计算。路径提示不代替当前变换，运行中
  修改 `tcp_placement.translation` 仍正确生效。
